Role Name
=========
A role to request Insights Image Builder to create image(s) based on yaml definitions.

Requirements
------------
See requirements here: https://github.com/enothen/ansible-image-builder/blob/main/README.md#prerequisites

Role Variables
--------------
api_endpoint: The url to interact with Insights image builder.
default_image_request: A dictionary with default values for architecture, image type and request type.
